# Trainingsplan

Eine React-App zur Vorbereitung auf körperlich fordernde Ziele (z.B. Spezialeinheit-Selektion):

- **Trainingspläne**: Übungen mit Sätzen, Wiederholungen, Gewicht und Notizen anlegen und bearbeiten.
- **Habits**: täglich abhakbare Gewohnheiten.
- **Challenge**: eine tägliche Challenge, deterministisch pro Tag ausgewählt.
- **Verlauf**: Diagramm & Tabelle zur Habit-Erledigungsquote der letzten 14 Tage.

Alle Daten werden aktuell nur lokal im Browser (`localStorage`) gespeichert.

## Entwicklung

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
